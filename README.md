# Virus Platformer (Python / Pygame)

## 起動

```bash
python -m pip install -r requirements.txt
python enemy.py
```

## 操作

- ←→: 移動
- Space: ジャンプ

※ プレイヤーの見た目（青い四角）は非表示にしています（キャラ担当が実装予定）。

敵を上から踏むと、敵が死んで「菌」と「炎」をばらまきます。
右へ進んで区画（画面）が変わると、菌の色テーマも変わります。

## 敵の攻撃

敵は生きている間、一定間隔でプレイヤー方向に「菌」または「炎」を発射します（大きい敵ほど頻度が高く、炎も混ざりやすい）。

見た目は「菌っぽさ」よりも、オリジナルの“かわいい敵キャラ”っぽいデザインに寄せています（既存作品のキャラそのものにはしません）。

## アニメ

- 敵：ぷるぷる脈動（呼吸っぽい） + ふわふわ浮遊 + ランダム瞬き
- 敵：プレイヤーが近いと照れて、ほっぺが濃くなる

## 見た目のバリエーション

敵は見た目が全員同じにならないように、トゲの本数/長さ・目の形・口の表情・体内模様がランダムで変わります。

## ばらまき（攻撃）

ばらまく「菌」はシンプルな丸で、炎もシンプルにしています（凝りすぎない）。

## 敵の種類

- S（小）: HP=1（1回踏めば倒れる）
- M（中）: HP=2（2回踏むと倒れる）
- L（大）: HP=3（3回踏むと倒れる）

大きい敵ほど、死亡時にばらまく菌の数も増えます。
